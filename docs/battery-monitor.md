# Монитор заряда половинок

`chbat` показывает заряд обеих половинок Charybdis, когда компьютер подключён к донглу напрямую по BLE. Донгл публикует два значения Battery Level, однако macOS рядом с именем клавиатуры обычно показывает только одно из них.

## Требования

- донгл с актуальной прошивкой из этого репозитория;
- BLE-соединение компьютера с устройством `Charybdis`;
- установленный [uv](https://docs.astral.sh/uv/);
- разрешение на доступ терминала к Bluetooth в macOS.

`uv` автоматически создаёт изолированное окружение и устанавливает Python-зависимость `bleak` при первом запуске.

## Безопасная зарядка половинок

Для зарядки подходит обычный качественный USB-порт на 5 В или исправный USB-C Power Delivery адаптер. Число ватт на корпусе адаптера — его максимальная доступная мощность, а не мощность, которую он принудительно передаёт подключённому устройству. Без отдельного USB-PD-согласования стандартный USB-C источник работает на 5 В; nice!nano не запрашивает повышенное напряжение и своим встроенным контроллером ограничивает заряд аккумулятора примерно до 100 мА. Это описано в [руководстве Texas Instruments по USB-C](https://www.ti.com/lit/eb/slyy228/slyy228.pdf) и [FAQ nice!nano](https://nicekeyboards.com/docs/nice-nano/faq/).

UGREEN CD333 на 300 Вт использовать можно. Его USB-C порты поддерживают базовый профиль 5 В, а более высокие напряжения доступны только совместимым устройствам после согласования. Поэтому исправный CD333 с обычным USB-C кабелем не заряжает клавиатуру на 100–140 Вт: фактический ток определяет зарядная схема nice!nano. Профили портов CD333 проверены в [разборе ChargerLAB](https://www.chargerlab.com/teardown-of-ugreen-300w-nexode-5-in-1-charger-cd333/).

Опасны или нежелательны:

- нестандартный или неисправный адаптер, который подаёт больше 5 В без согласования;
- PD-trigger кабель или переходник, принудительно включающий 9, 12, 15, 20 или 28 В;
- подача питания от адаптера напрямую на контакты аккумулятора `B+`/`B-` в обход зарядной схемы (подключать к ним сам совместимый LiPo — нормально);
- неперезаряжаемый аккумулятор или аккумулятор с номинальным напряжением, отличным от 3,7 В;
- перепутанная полярность аккумулятора;
- LiPo ёмкостью меньше 100 мА·ч при штатном токе зарядки nice!nano;
- включённый 500-мА boost jumper с аккумулятором, который не рассчитан на такой ток.

nice!nano рекомендует аккумуляторы 3,7 В ёмкостью примерно 100–500 мА·ч для штатного режима зарядки. Более маленький аккумулятор заряжается слишком большим относительно его ёмкости током, что сокращает срок службы; требования к аккумуляторам и boost jumper приведены в [документации nice!nano](https://nicekeyboards.com/docs/nice-nano/).

Во время зарядки аккумулятор и плата не должны заметно нагреваться. Если LiPo вздулся, пахнет, повреждён или становится горячим, отключите кабель, перестаньте использовать половинку и замените аккумулятор. Для проверки проблем с быстрым разрядом полезнее заряжать половинку до завершения зарядки, затем отключать кабель и измерять падение заряда, а не постоянно держать её подключённой.

## Установка команды в PATH

Из корня репозитория выполните:

```sh
make install-battery-cli
```

Установщик создаст символическую ссылку `~/.local/bin/chbat` на `tools/chbat`. Он не перезаписывает существующий файл или ссылку на другую программу.

Если после установки оболочка не находит `chbat`, добавьте каталог в `PATH`. Для стандартной оболочки zsh в macOS добавьте в `~/.zshrc`:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

Затем откройте новое окно терминала или примените конфигурацию в текущем:

```sh
source ~/.zshrc
```

Проверить установку можно так:

```sh
command -v chbat
chbat --help
```

Команда является ссылкой на файлы репозитория, поэтому репозиторий после установки нельзя перемещать или удалять. После `git pull` команда автоматически использует обновлённую версию утилиты.

### Другой каталог установки

Каталог можно передать через Make:

```sh
make install-battery-cli BATTERY_CLI_BIN="$HOME/bin"
```

Или вызвать установщик напрямую:

```sh
CHBAT_BIN_DIR="$HOME/bin" ./scripts/install-chbat
```

Выбранный каталог также должен входить в `PATH`.

## Использование

Без аргументов запускается полноэкранный TUI:

```sh
chbat
```

Режимы можно выбрать явно:

```sh
chbat --tui
chbat --short
```

`--short` один раз считывает оба значения, печатает их и завершает работу. Он удобен для быстрой проверки из терминала.

В TUI доступны две клавиши:

- `r` — заново найти устройство и подключиться;
- `q` — выйти.

Без установки в `PATH` утилиту можно запускать из корня репозитория:

```sh
make battery-tui
make battery-read
```

## Параметры подключения

По умолчанию утилита ищет устройство, имя которого содержит `Charybdis`, и подписывает батареи в порядке привязки половинок к донглу как `Left` и `Right`.

Для другого имени и русских подписей:

```sh
chbat --name Charybdis --labels Левая,Правая
```

Если значения относятся не к тем половинкам, поменяйте подписи местами:

```sh
chbat --labels Правая,Левая
```

Основные дополнительные параметры:

- `--address UUID` — подключиться по точному адресу; в macOS это CoreBluetooth UUID;
- `--scan-timeout SECONDS` — время одного BLE-поиска;
- `--poll-interval SECONDS` — интервал опроса в TUI;
- `--help` — показать все параметры.

Аргументы можно передать и Make-целям:

```sh
make battery-tui BATTERY_TUI_ARGS='--name Charybdis --labels Левая,Правая'
```

## Особенности macOS и решение проблем

При первом запуске разрешите Terminal, iTerm или другому используемому терминалу доступ к Bluetooth в системных настройках macOS.

Подключённая клавиатура часто перестаёт публиковать BLE-рекламу. Поэтому на macOS утилита сначала ищет уже подключённое системное устройство через CoreBluetooth и лишь затем запускает обычное сканирование.

Если после перепрошивки донгла утилита не видит два значения или macOS продолжает показывать старые `100%`, удалите сопряжение `Charybdis` в настройках Bluetooth и создайте его заново. macOS может кэшировать прежний список GATT-сервисов.

Если TUI нашёл устройство, но показания не обновляются, нажмите клавишу на соответствующей половинке: во время бездействия ZMK может держать последнее полученное значение заряда.
